# Aureum Mall & Residences — 360° architectural tour

Interactive architectural concept tour with 17 spherical scenes, navigation hotspots, responsive controls and locally AI-enhanced imagery.

Panoramas are 3840 × 1920 pixels. Unseen surroundings and room connections are illustrative architectural concepts. These images are not measured floor plans or a survey of the building.

The source architects' images remain available through the tour's reference comparison panel. Image enhancement preserves framing and proportions; fine detail is inferred by the restoration model.

## Publishing

Serve this repository as a static site. The entry point is `index.html`. GitHub Pages is configured for the main branch and repository root.
